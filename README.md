# 🍔 FoodHub – Online Food Ordering Website

## 📌 Project Overview

FoodHub is a fully responsive, single-page web application that simulates a modern online food delivery experience inspired by platforms like **Foodpanda**. It allows users to browse a dynamic menu, filter items by category, manage a shopping cart, and complete a checkout process with client-side payment validation.

The project is built entirely with **HTML, CSS, and JavaScript**, making it lightweight, fast, and easy to deploy.

---

## ✨ Features

### 🍕 Dynamic Menu Display
- Displays food items with name, emoji, description, and price.
- Menu data is stored in a JavaScript array for easy maintenance.
- Easily add, remove, or modify menu items.

### 🔍 Smart Category Filtering
- Filter food items by category:
  - All
  - Pizza
  - Burger
  - Sushi
  - Pasta
  - Dessert
- Updates instantly without reloading the page.

### 🛒 Interactive Shopping Cart
- Add items with one click.
- Increase or decrease item quantity.
- Automatically updates:
  - Cart subtotal
  - Delivery fee
  - Grand total
- Cart badge displays the total number of selected items.

### 💳 Secure Checkout
Collects:
- Customer name
- Delivery address
- Phone number

Supports payment methods:
- Credit/Debit Card
- PayPal
- Cash on Delivery

Card details are displayed only when required.

### ✅ Form Validation
Validates:
- Required fields
- 16-digit card number
- Expiry date (MM/YY)
- 3-digit CVV

### 🎉 Order Confirmation
After a successful order, users receive:
- ✅ Success message
- Random Order ID
- Total amount paid
- "Go to Home" button
- Automatic cart reset
